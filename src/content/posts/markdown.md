# 一级标题

段落之间用空行分隔。

第二段。_斜体_、**粗体** 和 `等宽字体`。项目列表看起来像这样：

- 第一项
- 第二项
- 第三项

注意，--- 不考虑星号 --- 实际文本内容从缩进 4 个空格的位置开始。

> 引用块的写法
> 就是这样。
>
> 如果你愿意，
> 它们也可以跨越多个段落。

使用 3 个短横线表示 em dash。使用 2 个短横线表示范围（例如 "第 12--14 章"）。三个点 ... 会被转换成省略号。
支持 Unicode。☺

## 二级标题

下面是一个编号列表：

1. 第一项
2. 第二项
3. 第三项

再注意一下，实际文本同样从第 4 列开始（距离左侧 4 个字符）。下面是一个代码示例：

    # 让我再重复一遍 ...
    for i in 1 .. 10 { do-something(i) }

你大概已经猜到了，这里缩进了 4 个空格。顺带一提，如果你愿意，也可以使用围栏代码块，而不是缩进代码块：

```
define foobar() {
    print "Welcome to flavor country!";
}
```

（这样更便于复制和粘贴）。你还可以为围栏代码块指定语言，让 Pandoc 对其进行语法高亮：

```python
import time
# Quick, count to ten!
for i in range(10):
    # (but not *too* quick)
    time.sleep(0.5)
    print i
```

### 三级标题

    - 芹菜
    - 扁豆

2. 把水烧开。

3. 把所有东西倒进锅里，然后按照
   这个步骤操作：

        找到木勺
        掀开锅盖
        搅拌
        盖上锅盖
        小心地把木勺搭在锅把上
        等 10 分钟
        回到第一步（或者完成后关火）

    不要碰到木勺，否则它会掉下来。

再注意一下，文本始终与 4 个空格的缩进对齐（包括上面第 3 项延续的最后一行）。
